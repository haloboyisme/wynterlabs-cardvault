# WynterLabs Cards

WynterLabs Cards is a self-hosted Version 1 collector for private trading-card
collections. It supports catalog browsing, collection tracking, exact-printing
review, CSV import and export, private collection-value history, deck building,
and optional browser-based scanning with user confirmation before a card is
saved.

## Privacy and data boundaries

Collections, account data, scanner photos, imports, and exports are controlled
by the installer. Scanner photos are transient: they are used to assist a
recognition request and are discarded rather than retained as a public image
library. Keep backups, secrets, and access controls under your own control.

Card names, images, rules text, set data, and price references belong to their
respective owners and providers. Follow each provider's attribution and
acceptable-use requirements. Values shown by the software are estimated
reference values, not appraisals.
