# Security policy

## Reporting a vulnerability

No public vulnerability-reporting address is configured yet. Do not post
vulnerability reports, exploit details, or suspected security issues publicly.

GitHub publication must remain private until the owner configures an
owner-controlled private reporting channel. When that channel is available,
use it for security reports and include a minimal reproduction, affected
version, impact, and any practical mitigation. Do not include secrets in a
report.

Never upload databases, card photos, keys, recovery codes, or production logs
to an issue, discussion, pull request, attachment, or report.

## Supported versions

Security fixes are intended for the `1.0.x` release line.
