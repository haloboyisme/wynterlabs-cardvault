# Version 2.5.1 release

Version 2.5.1 is the final Version 2 maintenance release. It does not add a new
authentication provider or database migration.

## Changes

- Removed unsupported-provider sign-in plans from current user-facing material.
  Google sign-in and local credentials remain the supported choices.
- Updated the Home release summary and moved all unfinished product ideas into
  the focused [Version 3 roadmap](V3-ROADMAP.md).
- Updated immutable installation instructions and the installer version guard.

## Verification

- Focused Home-page behavior and production build passed using the previously
  verified Docker build environment.
- Documentation links, release-version references, shell syntax, patch format,
  and the public secret/personal-information scan passed.
- This patch follows the verified V2.5 clean-install, upgrade, signup, Google,
  email, backup, and recovery evidence in
  [V2.5 release readiness](v2.5-release-readiness.md).

Version 3 work remains experimental and is promoted publicly only after private
owner acceptance. Version 2.5.1 remains the immutable feature-release record;
Version 2.5.2 adds only final documentation cleanup.

## Release status

Complete. Version 2.5.1 was published to the `v2` and `v2.5` branches, tagged
immutably, marked as the latest GitHub release and verified on the private Home
deployment. The documentation-only follow-up does not reopen Version 2 feature
development; all new product work is tracked under Version 3.
