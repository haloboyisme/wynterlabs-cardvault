# Version 2.7.5 — presentation, personalization and site design

Released September 12, 2026 on the v2 release line.

## Included

- Streamer Studio with seven reveals, eight backgrounds, four layouts, custom
  flip backs, per-event sounds, revocable OBS preview and pack recap/video export.
- Distinct found/accepted feedback and customizable USD price-tier celebrations.
- 42 Base Modes, seven dynamic interface-inspired looks, optional click/hover tones,
  low-power controls and reduced-motion support.
- Refreshed Account, Admin, Home and Dashboard; collapsed extra collection stats.
- Shared Brand Studio identity, design, copy, navigation and section controls.
- Smaller unchanged overlay responses and reduced hidden-tab polling.

All V2.6 scan preferences, pricing/history, Custom Card Import, existing scanner
simulation and standalone installation features remain. The private physical
Hardware Lab, firmware and deployment records are excluded.

## Upgrade

Follow [UPGRADING](UPGRADING.md) from the new release checkout. Preserve secrets and
make a verified backup. Migrations 0022_presentations and 0023_brand_design add
account-owned presentation storage and shared design settings. Existing preferences
receive compatible defaults; saved mute choices are preserved. Branding reads are
now available before sign-in; editing remains restricted.

## Verification and limits

The exact public candidate is checked with frontend tests, TypeScript, production
build, targeted API tests, lint, migration checks and installer shell syntax.
See the publishing checklist for the final measured test record.
The private live delivery had desktop/mobile sample previews and local video
playback/export checks. Real difficult-card acceptance, prolonged phone/tablet
camera sessions and actual OBS desktop audio routing remain outstanding.
No fresh clean-host installation or populated backup/restore drill is claimed.
The existing large-bundle build advisory remains. No paid service or dependency
was added. Video export depends on browser codecs and does not export alpha.
