# Version 2.6.0 — remembered scans, pricing and scanner refinement

Released September 10, 2026. Includes the pricing/chart work previously tracked
as the private V2.5.10 candidate and the completed V2.6 scan preference update.
Existing V2.5.9 and earlier tags remain unchanged.

## Included

- Remember the last scanning game/set per account and game on the current browser.
  Auto clears the set; missing sets fall back gracefully. No cross-device sync.
- Daily server-side TCGCSV cache, private per-card price details, and a separate
  collection-wide sales-based value with matched-copy coverage, stale timestamps
  and an asking-price comparison for the same copies.
- Interactive dashboard history with numeric axes, proportional time spacing,
  keyboard/touch slider, exact values and a data table.
- Either-half split/Room title matching, stricter ambiguous-printing selection,
  and 45-second matching timeouts retaining captures for retry.
- Foil/promo and long-session review guidance; manual confirmation stays required.
- Updated README, Home updates and remaining-work roadmap. Custom Card Import
  and the prior collection/account features remain included.

## Limits

Market Price summarizes sales; eBay completed-sale totals are not imported.
Prices mix conditions and exclude shipping/fees. Unmatched cards are excluded
from the sales-based total, never silently replaced with catalog estimates.
Automatic foil detection, new local-OCR timeouts, streamer effects, Bluetooth
and tabletop play are not included. Physical camera/card and long-session
acceptance remains pending. The private Hardware Lab and firmware stay private;
the existing public automatic-scanner test interface is unchanged.

## Upgrade and validation

Use the v2.6.0 tag and existing standalone upgrade helper. Back up first and
preserve installation secrets. There is no new migration beyond
0021_custom_cards; upgrades from older releases still apply intervening migrations.
The market cache reuses catalog-media storage and adds no dependency or paid key.

35 API and 140 frontend regression tests passed, alongside lint, TypeScript
and production-build checks covering the public integration. The feature updates were also deployed and visually
checked on the private installation. A new clean-host installation drill was not
run for this release; existing installer/recovery behavior is preserved.
