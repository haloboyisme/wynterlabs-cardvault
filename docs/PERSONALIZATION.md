# Personalization and shared branding

## Personal workspace

Open Account → Look & comfort. There are 42 Base Modes including System and seven
new original interface-inspired designs: Classic Desktop, Console Wave, Console Blue,
Orbit Pearl, Glass Desktop, Terminal and Arcade City. Desktop/console inspiration
does not mean an operating-system emulator or affiliation with its vendor.
Preferences follow the existing browser-local appearance settings across pages.

Motion & interface sounds controls moving backgrounds, low-power mode, click/hover
sounds and volume. Low-power defaults on; interface sounds default off and need a
user gesture. These controls are separate from streamer master mute. Existing text,
contrast and reduced-motion settings remain. At most two slow background layers
are used (one in low-power mode); motion pauses in hidden tabs and on Scan, and
accessibility settings can suppress it. Sounds are generated locally without downloads.
No measured power/FPS claims are made; these are bounded rendering and transfer changes.

## Shared site design

Authorized administrators use Admin → Site & branding → Brand Studio. Edit site
identity/logo, decorative colors, System background default, headings, corners,
finish, page width, section navigation, Home artwork/sections, Dashboard widgets,
welcome text, footer and announcement. Preview, discard or reset the draft, then
save to apply it. Personal accessibility choices remain. Hiding a section does
not delete its data or grant/revoke permissions. This is a defined collection of
brand/layout controls, not a general-purpose page editor.

Site identity/logo/design can be read without login so Home and sign-in display
the brand. Changes retain administrator authorization; account and collection
information is not part of the public branding response.

Account/Admin/Home/Dashboard use clearer headings and matching section layouts.
More collection stats starts closed and opens when selected.
